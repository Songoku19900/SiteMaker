📘 Bien démarrer avec SiteMaker
Guide facultatif — tu peux le rouvrir quand tu veux.

Ce guide t'explique les bases pour construire un site, personnaliser son apparence et comprendre le code généré. Tu peux tester les étapes directement dans SiteMaker.

1. Ajouter du contenuDans la colonne de gauche, clique sur Titre, Texte, Image, Bouton ou un autre bloc. Le bloc apparaît dans l'aperçu.
2. Modifier un blocClique sur un élément dans l'aperçu. Dans Propriétés, change son texte, ses couleurs, sa taille et son alignement. Les changements sont sauvegardés dans ce navigateur.
3. Créer des titres H1 à H6Ajoute un bloc Titre, puis choisis le niveau HTML dans ses propriétés. En général, utilise un seul H1 principal, des H2 pour les grandes parties et H3-H6 pour les sous-parties.
4. Régler un boutonSélectionne le bouton et ajuste sa largeur, sa hauteur, la taille du texte et l'espace intérieur. Une largeur à 0 signifie « automatique », selon le texte.
5. Ajouter tes imagesDans un bloc Image, colle une adresse d'image ou importe un fichier. Le bloc Diaporama permet plusieurs images ; Galerie les affiche ensemble. Les gros fichiers peuvent rendre le projet lourd.
6. Tester sur téléphoneUtilise les boutons Ordinateur / Téléphone au-dessus de l'aperçu. Vérifie les textes, images et boutons avant d'exporter.

Comprendre les trois langages

  • HTML : la structure et le contenu (titres, paragraphes, images, liens).
  • CSS : le style (couleurs, tailles, espacements, disposition).
  • JavaScript : les actions et interactions (menus, diaporamas, boutons dynamiques).

Petit exemple HTML

<h1>Bienvenue sur mon site</h1>
<p>Voici ma première page.</p>
<a href="https://example.com">Visiter un site</a>

H1 est le titre principal ; p est un paragraphe ; a est un lien. Les balises HTML sont généralement ouvertes puis fermées.

Modifier le code

Dans le panneau de droite, choisis HTML, CSS ou JS. Modifie le code puis clique sur Appliquer le code. Attention : appliquer un HTML personnalisé peut convertir les éléments simples en blocs et les éléments complexes en blocs de code HTML.

Sauvegarder et publier

  1. Clique sur Sauvegarder pour garder le projet dans ce navigateur.
  2. Utilise Projet JSON pour télécharger une sauvegarde modifiable que tu pourras réimporter.
  3. Clique sur Tester pour voir le site dans un nouvel onglet.
  4. Clique sur Exporter HTML pour obtenir le fichier de ton site. Pour le mettre en ligne, dépose le fichier exporté sur un hébergeur comme GitHub Pages.

Quelques conseils utiles

  • Fais une sauvegarde JSON avant de tester de grosses modifications.
  • Évite de coller du code trouvé au hasard : il peut contenir des erreurs ou des scripts dangereux.
  • Ne mets jamais de mot de passe, clé privée ou clé secrète dans le JavaScript public d'un site.
  • Ajoute un texte alternatif aux images pour l'accessibilité.
  • Teste les liens et les boutons avant de publier.
